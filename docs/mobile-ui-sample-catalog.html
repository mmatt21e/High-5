Interface samples

Each direction shows the same two moments: entering a table and taking a turn. The game screen keeps score, turn state, legal rows, and the local hand continuously clear.

Playing-card samples

Every direction keeps a familiar physical-card silhouette, redundant suit shapes, strong contrast, and exposed corner indexes for fanned hands.

Each face row includes numeric and court ranks across all four suits. The second row demonstrates selected and unavailable states plus original Five-O back patterns. Scroll a row horizontally on a narrow phone.
